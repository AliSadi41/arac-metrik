Neden Bu Proje?

İkinci el araç piyasası Türkiye'de hem büyük hem de karmaşık. Fiyatlar marka, model, yıl, km, şehir ve renge göre dramatik biçimde değişiyor. Bu karmaşıklık, makine öğrenmesi için iyi bir problem.

Portföy projesi olarak seçildi çünkü hem veri mühendisliğini hem modellemeyi hem de kullanıcı arayüzünü tek pakette gösteriyor. Bir işveren/recruiter uygulamayı açtığında tüm yetkinlikleri tek ekranda görebiliyor.

02 — Veri

Veri: Nereden, Nasıl?

Ham veri Kaggle'dan alındı. 253.344 ilanın 250.955'i temizleme sonrası kaldı. Temizleme src/temizle.py ile yapıldı.

Kaynak

📂 Kaggle — Turkey Used Cars Marketplace December 2025
CC0 (public domain) lisanslı dataset. Aralık 2025 kesiti. Türkiye geneli tüm markaları ve şehirleri kapsıyor. Ham CSV yaklaşık 70 MB.

Ham veri repoda yer almıyor (git dışı). Bunu kasıtlı yaptık — büyük dosyaların repoda bulunması performansı düşürür. Bunun yerine işlenmiş veriyi (data/processed/arac_temiz_v3.csv) repoya ekledik çünkü Streamlit Cloud'un bunu çalıştırması için gerekli.

Neden log1p Dönüşümü?

Fiyatlar çarpık dağılımlı: çoğu ilan 200k–1.5M TL arası ama bazıları 15–20M TL'ye kadar çıkıyor. Bu uç değerler modeli bozar.

Çözüm: Fiyata log1p uygulanıyor, tahmin sonrası expm1 ile geri dönüştürülüyor. Bu sayede model sapmaları yüzdelerle ölçüyor, mutlak TL farkıyla değil.

# Eğitimde
y_train = np.log1p(df_train['fiyat'])

03 — Makine Öğrenmesi

Model: LightGBM Neden?

4 farklı model denendi. LightGBM en yüksek R² ve en düşük hata ile kazandı. Ama sadece "daha iyi" olduğu için değil — hızı ve kategoriklerle çalışma biçimi de önemli.

Model Karşılaştırması

ModelR²Ortanca Hataİlerleme
Taban (yalnızca yıl) 0.549 %24.5
Ridge (linear) 0.944 %8.4
Random Forest 0.965 %6.3
LightGBM ✓ 0.968 %5.9

Test kümesi: 50.191 ilan (rastgele %20 ayrım, random_state=42)

LightGBM Neden Seçildi?

⚡ Histogram tabanlı gradient boosting
Veriyi önce histogramlara böler, sonra bu histogramlar üzerinde çalışır. 250k satırlık veriyle dakikalar içinde eğitildi. Random Forest aynı sonucu vermek için çok daha uzun sürer.
🏷️ Kategorik sütunları native destekler
Marka, model, şehir gibi kategorik sütunlar için özel one-hot encoding gerekmez. LightGBM bunları kendi içinde işler. Bu hem kod temizliği sağlar hem de modeli daha iyi sonuç verir.
📉 Overfitting'e dirençli
Boosting iterasyonları early stopping ile kontrol edildi. Model, eğitim setini ezberlemek yerine genelleştirmeyi öğrendi. Train R²=0.981, test R²=0.968 — aradaki fark küçük.

R² Nedir?

R² = 1 → Model mükemmel tahmin yapıyor. R² = 0 → Model sadece ortalamayı tahmin ediyor (taban model).

R²=0.968 demek: fiyat varyansının %96.8'ini model açıklıyor. Geriye kalan %3.2'si modelin göremediği şeyler — hasar geçmişi, ilan fotoğrafı kalitesi, satıcı aciliyeti gibi.

Ortanca Hata %5.9 Ne Demek?

Median absolute percentage error. 1.000.000 TL'lik bir araç için ±59.000 TL demek. Ortalama değil ortanca — büyük uç değerler bunu şişirmiyor.

04 — Streamlit Uygulaması

6 Sekme, Her Biri Ne Yapar?

app/panel.py tek bir dosyada yazıldı. Streamlit'in sekme sistemiyle 6 analiz modülü oluşturuldu. Her sekme bağımsız bir analiz aracı.

🔍Fiyat Tahmini
Kullanıcı marka/model/varyant + yıl/km/şehir/renk girer. LightGBM modeli çalışır. %80 güven aralığı ve hangi özelliğin fiyatı ne kadar etkilediği grafikte gösterilir.
📉Değer Kaybı
Seçilen araç için yıl bazında medyan fiyat eğrisi çizilir. Altair ile interaktif grafik: bant (q25–q75), toplam kayıp yüzdesi, yıllık ortalama düşüş.
💡Fırsat Dedektörü
Kullanıcı ilan fiyatını girer. Benzer araçların fiyat dağılımıyla karşılaştırılır. Yüzdelik dilim hesaplanır: "Harika Fırsat" → "Pahalı" skalasında skor verilir.
📊Piyasa Genel Bakış
250k ilanın marka, yakıt, yıl, şehir dağılımı. 4 interaktif Altair grafiği. Kullanıcı trendi tek bakışta anlayabilir.
🏆En İyi Fırsatlar
Piyasa ortancasından ≥%15 ucuz ilanlar filtrelenir. Marka ve minimum indirim filtresi. Hover tooltip'lerle detaylı metrikler.
✨Karşılaştırma
Birden fazla marka seçilir, yıl bazında fiyat eğrileri yan yana çizilir. "Ford mu Toyota mı daha hızlı değer kaybediyor?" sorusu cevaplanabilir.

Hover Tooltip'li Metrik Kartlar

Streamlit'in standart st.metric() bileşeni hover desteklemiyor. Bu yüzden custom HTML kartlar yazdık:

def metric_row(cards):
    parts = []
    for c in cards:
        tip_html = (
            f'<div class="mc-tip">{c["tooltip"]}</div>'
            if c.get("tooltip") else ""
        )
        parts.append(
            f'<div class="mc-card">'
            f'<div class="mc-label">{c["label"]}</div>'
            f'<div class="mc-val">{c["value"]}</div>'
            f'{tip_html}</div>'
        )
    st.markdown(
        f'<div class="mc-row">{"".join(parts)}</div>',
        unsafe_allow_html=True
    )

# CSS: hover'da tooltip görünür

05 — Stack

Teknolojiler

Her kütüphane belirli bir görevi için seçildi. "Popüler olduğu için" değil, "bu işi en iyi o yapıyor" mantığıyla.

Python 3.12
Ana dil
Veri bilimi ekosisteminin standartı. 3.12 seçildi çünkü LightGBM 4.7 ve pandas 3.0 ile tam uyumlu, performansı da önceki versiyonlara göre belirgin biçimde artmış.
pandas 3.0
Veri manipülasyonu
CSV okuma, filtreleme, gruplama, birleştirme. 250k satırlık veriyi bellekte tutup hızla işlemek için. groupby, merge, cut yoğun kullanıldı.
Neden pandas 3? Copy-on-write varsayılan — bellek kullanımı azaldı.
LightGBM 4.7
Makine öğrenmesi modeli
Microsoft'un geliştirdiği gradient boosting kütüphanesi. Histogram tabanlı yapısı sayesinde büyük veriyle çok hızlı. Kategorik sütunları native destekler — marka/model/şehir için mükemmel.
R²=0.968, ortanca hata %5.9 → 4 model içinde açık ara birinci.
scikit-learn
ML yardımcıları
Train/test split, Ridge regresyon (karşılaştırma için), metrik hesabı (r2_score, mean_absolute_percentage_error). LightGBM'in rakiplerini test etmek için kullanıldı.
Streamlit 1.66
Web arayüzü çatısı
Python kodu doğrudan web uygulamasına dönüşüyor — HTML/JS yazmadan. st.tabs(), st.selectbox(), st.columns() ile 6 sekmeli arayüz oluşturuldu.
Veri bilimciler için ideal: frontend bilgisi gerekmez, deploy kolay.
Altair
İnteraktif grafikler
Vega-Lite üzerine kurulu declarative grafik kütüphanesi. Değer kaybı eğrisi, güven bandı, fırsat histogram — hepsi Altair ile. Streamlit içinde st.altair_chart() ile gösteriliyor.
Pillow
Favicon üretimi
Tarayıcı sekmesindeki OP ikonu Pillow ile çalışma zamanında üretiliyor. Harici dosya yok — ImageDraw ile daire ve çizgiler kod içinde çiziliyor.
Streamlit page_icon= parametresi PIL Image kabul ediyor.
06 — Yayına Alma

Deploy: Nasıl Canlıya Alındı?

Streamlit Cloud, GitHub reposuna bağlı ücretsiz bir hosting hizmeti. Push yaptığında otomatik yeniden deploy ediyor.

Deploy Akışı

1
GitHub reposu oluşturuldu — arac-metrik adıyla public. Model dosyaları ve işlenmiş veri repoda, ham veri .gitignore'da.
2
requirements.txt hazırlandı — Streamlit Cloud bu dosyayı okuyarak pip install yapıyor. Her kütüphane sürümü sabitleniyor (lightgbm==4.7.0 gibi).
3
.streamlit/config.toml — Tema renkleri, port ayarları buraya yazılıyor. primaryColor = "#38bdf8" ile sky blue vurgu rengi tanımlandı.
4
share.streamlit.io'da "New app" → GitHub repo bağlandı → app/panel.py entry point olarak seçildi → Deploy.
5
Canlı link alındı — arac-metrik-pnvt2xmpxif4wsjwewvsvt.streamlit.app. GitHub About bölümüne ve README'ye eklendi.

Neden Streamlit Cloud?

✅ Ücretsiz — public repolar için
Kredi kartı gerekmiyor. 1 GB RAM, otomatik uyku modu (30 dk aktivite yok ise uyuyor, ilk açılışta birkaç saniye bekliyor).
🔄 GitHub'a bağlı CI/CD
git push yaptığında Streamlit Cloud otomatik yeni versiyonu deploy ediyor. Manuel işlem yok. Değişiklik → push → birkaç dakika → canlı.
